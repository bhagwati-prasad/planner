# 12. Data visualisation

- **Time series** for metrics: line charts with 1.5 px lines. Percentiles use one colour with different dashes: p50 solid, p95 dashed, p99 dotted.
- **Distributions:** histograms for latency, with p50, p95 and p99 markers.
- **SLO thresholds:** a 1 px dashed danger line labelled with its value.
- **Axes:** small text in secondary colour, units in the axis title, hairline gridlines in subtle border colour, and no chart borders.
- **Tooltips:** a crosshair with all series values at that time, in tabular figures.
- **Series:** at most six, using the categorical palette in order; group the rest as "Other".
- Every chart has a text summary for screen readers, and a "View as table" toggle.
