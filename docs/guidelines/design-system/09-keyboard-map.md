# 9. Keyboard map

Mod means Cmd on macOS and Ctrl elsewhere. The full list opens with Mod+/.

| Action | Keys |
| --- | --- |
| Command palette | Mod+K |
| Keyboard shortcuts | Mod+/ |
| Select tool, hand tool | V, H (hold Space for temporary hand) |
| Search library | / |
| Find on canvas | Mod+F |
| Comment on selection | C |
| Add note | N |
| Rename | F2 or double-click |
| Drill into inner system | Enter |
| Deselect, then go up a level | Escape |
| Move focus between nodes | Arrow keys |
| Cycle through a node's connections | E, Shift+E |
| Nudge by one grid step, by 1 px | Shift+Arrow, Alt+Shift+Arrow |
| Undo, redo | Mod+Z, Mod+Shift+Z |
| Copy, cut, paste, duplicate | Mod+C, Mod+X, Mod+V, Mod+D |
| Delete from model | Delete or Backspace |
| Hide from this view only | Shift+Delete |
| Group in a frame, ungroup | Mod+G, Mod+Shift+G |
| Extract as system, inline system | Mod+Alt+G, Mod+Alt+Shift+G |
| Select all at this level | Mod+A |
| Zoom to fit, 100%, in, out | Mod+0, Mod+1, Mod+=, Mod+- |
| Switch mode (Design to Plan) | Alt+1 to Alt+6 |
| Outline view | Mod+Shift+O |
| Play or pause | Mod+Enter or F8 |
| Stop | Mod+. |
| Restart | Alt+Home |
| Run to end | Alt+End |
| Step forward n, step back n | F10, Shift+F10 |
| Step into, step out | Alt+F10, Alt+Shift+F10 |
| Change step unit | Alt+U |
| Follow the selected request | Alt+F |
| Toggle breakpoint on selection | F9 |
| Open as system | Mod+Alt+O |
| Save to file | Mod+S |

Shortcuts never override browser-reserved keys that cannot be reliably intercepted, such as F11 and Mod+W. Canvas and run shortcuts don't fire while typing in a field.
