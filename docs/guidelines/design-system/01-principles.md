# 1. Principles

Seven principles settle design arguments. When two conflict, the earlier one wins.

- **Canvas first.** The diagram is the brightest, most detailed thing on screen. Panels are quiet, flush and hairline-divided so the architecture carries the colour.
- **Depth is always visible.** At any moment people can see which level they are on, how deep it goes, and which components contain their own systems. This is Strata's signature (§5).
- **Every design is runnable.** The run controls are always on screen, and the canvas itself is the simulator: requests, state and results appear where the components are.
- **Every number carries its unit and its source.** A value shows its unit, and whether it is a default, an override or a roll-up.
- **Calm until it matters.** Colour is reserved for selection, state and simulation results. Decoration never uses status colours.
- **Keyboard parity.** Everything a pointer can do, the keyboard can do, and so can the console.
- **One way to do each thing.** One selection model, one inspector, one comment system and one command palette, in every mode.
