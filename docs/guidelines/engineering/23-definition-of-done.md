# 23. Definition of done

- [ ] Works from `file://` and when served, in Chrome, Edge, Firefox and Safari.
- [ ] Available through the facade and the console, with `help` metadata.
- [ ] Every change is a command; undo and redo work; the op log entry is correct.
- [ ] Survives reload, and a `.strata` export and import round-trip.
- [ ] Tested at the required levels; determinism is preserved.
- [ ] Runnable: new component types simulate as a black box with realistic defaults, expose typed state, and work with every step unit, scope and stub mode.
- [ ] Recursive fixture covered wherever systems are involved.
- [ ] Comments can anchor to any new entity type.
- [ ] Keyboard and screen-reader behaviour meet the UI/UX Design System.
- [ ] Light, dark and contrast themes verified; styling uses tokens only.
- [ ] Performance budgets hold.
- [ ] JSDoc, README and any required ADR are updated.
