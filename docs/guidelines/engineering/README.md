Engineering rules, one file per section. Changes need an ADR in docs/adr/.

Version 2.0, 26 September 2026. These rules apply to every Strata package from R0 onward. They implement version 2.0 of the Product and Technical Specification. Any change to this document needs an ADR (§20).
